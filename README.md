# Power BI Report Repository

This repository contains the source files and definitions for a Microsoft Power BI report. 

## Repository Structure

* `Report/definition/` - Contains the core report layout, pages, and visual configurations (`report.json`, pages, and visual definitions).
* `Report/StaticResources/` - Includes theme configurations and shared design resources (e.g., Fluent UI themes).
* `DataModel` - Houses the underlying data model structure.
* `SecurityBindings` - Contains security and access configurations.
* `DiagramLayout` - Stores layout positioning for data modeling views.
